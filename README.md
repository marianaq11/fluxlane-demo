# Fluxlane — Front-End Showcase

A single-page, fully responsive concept landing page built to demonstrate front-end development skills: layout, interaction design, and vanilla JavaScript — no frameworks, no build step.

**Fluxlane is a fictional product.** This is a design/development exercise, not a real company or SaaS.

[Live demo →]([https://marianaq11.github.io/fluxlane-demo/])
## What it demonstrates

- Responsive, mobile-first layout built with plain CSS (Grid + Flexbox, no framework)
- Light/dark theme switch using CSS custom properties
- Scroll-triggered reveal animations via the Intersection Observer API
- An animated, count-up stats section
- Interactive components built from scratch: tabbed content panels, a testimonial carousel, a pricing table with a monthly/annual toggle, and an FAQ accordion
- A custom-built bar chart with hover tooltips (no charting library)
- Accessible color choices and readable typography at every breakpoint

## Tech

HTML5, CSS3 (custom properties, Grid, Flexbox), vanilla JavaScript (ES6+). No dependencies, no build tools, you can open index.html straight in a browser and everything works.


## Why I built this

Built as a portfolio piece to showcase front-end craft — clean component structure, attention to interaction and motion detail, and accessible, production-style styling.
