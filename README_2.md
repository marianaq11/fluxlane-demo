# Fluxlane — a front-end practice project

A single-page concept website I built to practice front-end development — layout, animations, and interactive JavaScript, all from scratch with no frameworks.

**Heads up:** Fluxlane isn't a real company or product. I made up the name and content so I'd have something realistic-looking to design around, instead of another to-do list tutorial app.

🔗 [Live demo](https://marianaq11.github.io/fluxlane-demo/)

## What's in it

- Fully responsive layout (works on phone, tablet, and desktop) using CSS Grid and Flexbox
- A light/dark mode toggle
- Scroll animations — sections fade in as you scroll, using the Intersection Observer API
- A stats section that counts up when it scrolls into view
- Interactive pieces I built myself: tabs, a testimonial slider, a pricing toggle, and an FAQ accordion
- A small bar chart with hover tooltips, built with plain HTML/CSS/JS — no chart library

## Built with

Just HTML, CSS, and vanilla JavaScript. No React, no build tools — you can open `index.html` straight in a browser and everything works.

## Why I made this

I wanted to practice things like responsive design, animations, and interactive UI components without leaning on a framework, and I figured a fake product page would push me more than a plain layout exercise would.
